## 2. 两条传递路径

### 2.1 动画层：FK 父子链

**观察**：`mot` 的骨架记录里每个关节带父/子/兄弟指针与局部位移/旋转，构成一棵树（em0071 共 182 关节）。受击动作对每个关节写曲线（受击 `plc_Damage_002` 有 90 条轨道、脊柱/头每 1.0–1.5 帧一个关键帧）。

**传递机制**：

```
W_child = W_parent · L_child        # 局部位移/旋转合成
```

- 父骨旋转 δ → 子骨及其整棵子树的**世界位置全部被带动**；
- 子骨自己的受击曲线再叠加在父级结果上，所以末端看到的是“父级抖动 + 沿链各级抖动”的累积；
- 这也是为什么受击动作只给关键骨骼写大振幅、末端自然被带出去。

### 2.2 程序化层：三种链

| 层 | 传递方式 | 数据证据 |
| --- | --- | --- |
| Shock absorber | 在若干关节/轴上加角偏移，沿 FK 向下游传递 | 每怪 10 组参数（角度限位、阻尼、速率） |
| Bend filter | 对脊柱/尾/翼按“骨骼组”做滤波后覆盖局部弯曲 | 50°/30°/5–10° 分档与 0.2–1.0 权重 |
| Chain2 | 真正的物理链：冲量从链根逐节传到末端 | 重力 -9.8、刚度 0.3/0.02/0.1、阻尼 0.05、碰撞过滤 |

## 3. 传递与放大的数学

- **角位移的杠杆臂放大**：父骨转 δ（弧度），末端线位移 ≈ δ × 到父骨的链长。em0071 的骨架段长（局部平移累加，模型单位）：

| 路径 | 段长和 |
| --- | --- |
| Hip → Head（脊柱+颈） | 6.33 |
| Hip → Tail4（尾） | 8.70 |
| Chest → L_WingU0（翼根） | 5.21 |
| Hip → L_Foot0（腿） | 5.82 |

  例：尾根 1° 的抖动（0.0175 rad）在 Tail4 末端约产生 `0.0175 × 8.70 ≈ 0.15` 单位的位移；5° 就是 0.76 单位——**同一角度在长链末端被放大**。

- **旋转合成**：父级旋转会旋转子级的本地轴，子级的抖动方向随之改变；多级叠加时方向不再与根一致，形成“甩鞭”效果。

## 4. 衰减机制与实测参数

### 4.1 Shock absorber：每关节独立的弹簧-阻尼 + 限位

em0071 的 10 组记录（见前作）给出每关节/轴的：

- 角度限位：`-90/180`、`-70/140`、`-30/120`；
- 阻尼：`0.10 / 0.20 / 0.25 / 0.30`；
- 回弹速率：`0.9 / 1.0 / 1.5 / 2.0 / 2.5 / 3.0 / 4.0`。

**推断**：阻尼越大、速率越低，抖动衰减越快；限位在末端决定“最多甩多远”。不同关节用不同参数，所以抖动沿身体是**分段衰减**而不是全局统一。

### 4.2 Bend filter：按组加权 + 限幅

- 组权重 `0.2 / 0.25 / 0.33 / 0.5 / 1.0`；
- 限幅 `5° / 10° / 30° / 50°`（walk 与 dash 在同一位置用 5° vs 10°，按步态切换）。

**推断**：权重小 → 跟随慢 → 高频抖动被滤掉；限幅小 → 该组骨骼最多弯这么多，超过就截断。脊柱（小角度）与尾/翼（大角度）因此有不同的抖动幅度。

### 4.3 Chain2：逐链刚度/阻尼 + 重力

抽样 em0071 的 `ch90_071_0000.chain2.13`（10,280 B）：**3 条链**，每条记录含：

- 重力 `-9.8`；
- 两组（两轴）刚度/阻尼：链 A `0.5 / 0.3`、链 B `0.02 / 0.02`、链 C `0.1 / 0.1`，阻尼均 `0.05`；
- 碰撞过滤 `System/Collision/Filter/Character/Character_Chain.cfil`。

**推断**：刚度高的链（0.3）摆动快、回位快；刚度 0.02 的链软，摆幅大、频率低；阻尼 0.05 决定每帧能量损失。受击冲量从链根注入后，末端按链参数延迟摆动——这就是“尾巴/毛发甩一下再停”的来源。

### 4.4 其他衰减手段

- **关节 LOD（`jointlodgroup`）**：距离远时部分关节不再更新，抖动在高 LOD 下消失；
- **joint mask（`jmap`）**：layer 只作用于掩码内的骨骼，掩码外的骨骼完全不参与；
- **Hitstop**：冻结/减速期间弹簧与物理链仍在积分，恢复瞬间叠加成更大的“弹一下”。

## 5. 骨骼自身姿态的影响（重点）

### 5.1 抖动方向随姿态旋转（本地空间）

角偏移施加在**关节本地空间**：同一“绕 X 轴 ±5°”的抖动量，在手臂水平与手臂下垂时，世界空间的摆动方向完全不同。父级姿态还会继续旋转这个方向（§3 的旋转合成）。

### 5.2 杠杆臂：骨越长、链越末端，位移越大

末端线位移 ≈ 角度 × 到旋转关节的链长（§3 表）。所以：

- 头/尾/翼末端对同样的角度最敏感；
- 短骨（手指、脚趾）几乎看不出抖动；
- 尾链 8.70 单位的杠杆臂让 1° 都能看到明显摆幅。

### 5.3 限位余量：姿态越接近限位，可用抖动幅度越小

- Shock absorber 的限位是**固定角度区间**（如 -90°~180°）。如果当前姿态已经把关节推到接近边界，剩余可用行程变小，抖动会被“顶住”；
- 这也是为什么受击时“手抬得很高”与“手自然下垂”两种姿态，肩部的抖动幅度不同。

### 5.4 静息姿态与重力：决定链的自然频率

物理链的摆动频率取决于“重力力矩 / 刚度”。静息姿态改变重力相对链的方向：

- 尾/毛发自然下垂 → 重力帮助摆动、频率低、摆幅大；
- 翼/横置的链 → 重力垂直于链，力矩小，更多由刚度决定频率；
- 三条链刚度差 15 倍（0.3 vs 0.02），所以同一次冲量下三条链的响应完全不同。

### 5.5 父级姿态改变传递路径与碰撞

- 父骨弯曲时，子骨的本地轴被旋转，抖动的“传播方向”改变；
- 碰撞过滤是角色专用（`Character_Chain.cfil`）：姿态变化会让链更容易/更少撞到身体，碰撞会额外消耗能量（衰减）；
- 关节 LOD/掩码可能随状态切换（如死亡状态 `DEAD` 关闭 shock absorber），姿态/状态会改变“哪些关节参与抖动”。

## 6. 一个直观的数值例子

- 尾根 1° 抖动 → Tail4 末端约 0.15 单位位移；3° → 0.46 单位；5° → 0.76 单位（杠杆臂 8.70）。
- 链阻尼 0.05/帧：如果按每帧衰减理解，1 秒（60 帧）后剩余 `0.95^60 ≈ 4.6%`（仅示意，实际是否按帧/秒语义未知）。
- Shock absorber 阻尼 0.30 的关节约 2–3 次过冲就停；阻尼 0.10 的关节会多晃几次（推断）。

## 7. 对 UE5 的实现建议

1. **FK 传递**不用额外做：父骨动画天然带动子骨；需要注意的只是“末端放大”，调参时按骨长补偿。
2. **冲击吸收**用 Control Rig 的弹簧节点（每关节独立 stiffness/damping/limit），受击时注入角速度；限位用 Clamp。
3. **弯曲滤波**用一阶跟随 + 角度 Clamp，按骨骼组配权重（脊柱 5°、尾/翼 30–50°）。
4. **物理链**用 Chaos Physics Asset / AnimDynamics，每条链单独调刚度/阻尼/重力与碰撞通道。
5. **衰减顺序**：先 FK → 冲击吸收 → 弯曲滤波 → 物理链 → 碰撞；物理链放最后，避免被上游修正反复拉扯。
6. **姿态相关**：调参时至少覆盖站立、奔跑、倒地三种姿态，验证限位余量与重力方向的影响。
