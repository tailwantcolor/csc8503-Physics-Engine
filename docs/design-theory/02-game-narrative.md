# 02 游戏叙事：空间、选择、涌现与机制

> 一句话：游戏叙事不是「把故事放进游戏」，而是「让故事从玩家的行动、空间和系统里长出来」。

## 1. 游戏叙事的两个来源：嵌入与涌现

Henry Jenkins 在《Game Design as Narrative Architecture》中区分了两类叙事来源：

- **嵌入叙事（embedded narrative）**：作者预先写好的故事——剧本、过场、日志、环境布置、道具描述。玩家去「发现」它。
- **涌现叙事（emergent narrative）**：系统运行与玩家行动产生的故事——战斗如何发生、NPC 如何反应、玩家如何失败又翻盘。玩家去「经历」它。

两者不是二选一，而是配比问题：

| | 嵌入叙事 | 涌现叙事 |
| --- | --- | --- |
| 控制者 | 作者 | 系统 + 玩家 |
| 优点 | 精确、可控、可演出高光 | 个性化、可复述、耐玩 |
| 风险 | 玩家被动、重复游玩价值低 | 不可控、可能不感人、难以保证节奏 |
| 适合 | 主线、角色关系、世界揭示 | 战斗、探索、生存、沙盒、多人 |

**判断配比的问题**：玩家在两次「作者安排的高光」之间，有没有值得自己做决定、自己产生故事的空间？如果没有，游戏会变成「按 A 看片」；如果全是系统，玩家可能不知道为什么要在乎。

## 2. 叙事架构：空间、环境、物件

Jenkins 把游戏讲故事的常见方式概括为四类（不同译本措辞不同，含义一致）：

1. **唤起式空间（evocative spaces）**：用玩家熟悉的叙事母题搭建世界，让玩家带着既有想象进入。
2. **演绎故事（enacting stories）**：玩家通过行动「重演」故事（任务、仪式、战斗）。
3. **嵌入叙事（embedded narratives）**：把故事信息埋进空间与物件，等待发现。
4. **涌现叙事（emergent narratives）**：让系统自己生成故事。

**环境叙事（environmental storytelling）的三条可操作原则**：

- **空间逻辑**：谁住在这里、他做什么、他怕什么——空间布局要能回答这些问题，而不只是「好看」。
- **视觉焦点**：玩家视线会被光、颜色、运动、独特形状吸引。把最重要的信息放在焦点上，把背景信息放在第二层。
- **信息分层**：第一层（路过就能懂）→ 第二层（停下来能看懂）→ 第三层（需要推理/拼合）。不要把所有信息都放在第一层。

**案例**：

- *Gone Home*：整个故事靠房间里的物件、便签、录音带拼出来，玩家没有战斗，只有「看」与「推断」。
- *Dark Souls* 系列：物品描述、敌人摆放、建筑尺度共同讲述一个没有明说的世界史。
- *BioShock*：环境与录音带揭示城市的意识形态崩塌，与主线反转互相支撑。
- *The Last of Us*：废弃建筑里的儿童画、临时隔离区、尸体摆放，持续回答「这里发生过什么」。
- *Elden Ring*：用遗迹、雕像、敌人类型和地形暗示历史与神系关系，几乎不靠过场解释。
- *Outer Wilds*：每个遗迹都是「知识」的载体，玩家读懂的每一段文字都直接变成可执行的新路线。

**环境叙事的陷阱**：

- 玩家还没有理由关心时，信息就是噪音；
- 信息太隐晦，玩家会完全错过；信息太直白，又变成说明书；
- 环境叙事不能替代角色关系：玩家可以为「这个地方发生过什么」感动，但很难为「一堵墙」感动。

## 3. Ludonarrative：机制与故事的四种关系

Clint Hocking 在 2007 年评论 *BioShock* 时提出 **ludonarrative dissonance（叙事与玩法失调）**：游戏机制鼓励的行为，与故事宣称的价值发生冲突。典型例子：故事说「生命可贵」，机制却让玩家为了资源屠杀 NPC；故事说「你是个好人」，机制却让玩家杀了上千人。

四种关系，不是只有「协调」一种正确答案：

| 关系 | 含义 | 例子 | 适用 |
| --- | --- | --- | --- |
| 协调（consonance） | 机制强化故事价值 | *Hades*：死亡是剧情的一部分，每次失败都推进关系 | 大多数叙事游戏的目标 |
| 失调（dissonance） | 机制与故事价值冲突 | *BioShock* 的「Would you kindly」；*Uncharted* 的「轻松杀手」 | 可以是失误，也可以是主题 |
| 把失调变成主题 | 让冲突本身成为表达 | *Spec Ops: The Line*：让玩家为「不得不开枪」感到不适 | 元叙事、批判性作品 |
| 机制不承载叙事 | 玩法优先，故事是包装 | 多数纯竞技/沙盒游戏 | 合法选择，但要诚实 |

**自检表**：故事承诺了什么价值？机制允许/鼓励什么行为？两者冲突时，玩家会感到「深刻」还是「被耍」？如果答案是「被耍」，通常不是玩家的问题。

## 4. 选择与后果

**「有意义的选择」需要同时满足**：

1. **知情**：玩家知道自己在选什么（至少知道风险与代价的方向）。
2. **有分量**：选项对应不同的价值，而不是「红药水/蓝药水」。
3. **有反馈**：选择后世界有可感知的变化。
4. **有持续**：后果在后续被记住、被引用、被兑现。

**选择的四种功能**（可以叠加）：

- **表达型**：让玩家说出「我是谁」（对话态度、阵营、外观）。
- **策略型**：让玩家做资源/风险权衡（build、路线、装备）。
- **叙事型**：改变剧情走向与角色关系。
- **道德型**：让玩家面对价值冲突，通常没有廉价的最优解。

**分支的成本与结构**：

- 真分支成本随深度指数增长，内容团队很难填满；
- 常用结构：**折返（foldback）**——分支后汇合，用变量记录差异；**枢纽—辐条（hub-and-spoke）**——中心枢纽+可探索支线；**珍珠链（string of pearls）**——线性主线下挂可选支线；**开放结构**——顺序自由，结果由系统结算。
- **幻觉选择**：如果玩家永远不会知道被隐藏的选项，低压力的「假选择」可以接受；但**用选择假装后果**、事后统一收束，会伤害信任。判断标准是：玩家回看时，是否觉得自己被尊重。

**后果的可见性**：后果不一定要「改变结局」，也可以是改变 NPC 的一句话、一个道具、一段环境细节。可见性比规模更重要。

## 5. 叙事机制化：把故事变成规则

**叙事机制（narrative mechanic）**：一个可重复的玩家动作，它的规则本身就在表达故事主题。

| 主题 | 机制化方式 | 代表作品 |
| --- | --- | --- |
| 死亡与放下 | 死亡不是失败，而是推进关系与解锁信息的循环 | *Hades* |
| 知识就是力量 | 进度由「知道什么」决定，而不是数值 | *Outer Wilds* |
| 连接与孤立 | 负重、路线、异步留下的设施 | *Death Stranding* |
| 记忆与身份 | 记忆碎片作为可拼合的系统 | *Return of the Obra Dinn* |
| 对话即人格 | 技能/属性作为内心声音参与对话 | *Disco Elysium* |
| 暴力与责任 | 让玩家执行「无法拒绝的命令」，再迫使玩家面对后果 | *Spec Ops: The Line* |
| 宽恕 | 允许「不杀」成为完整通关路径 | *Undertale* |

**设计方法**：从主题动词出发——记住、放下、连接、证明、背叛、等待、修复——问「哪个动词可以变成玩家反复执行的动作？」机制必须真的改变结果；如果只是换一段台词，那还是嵌入叙事。

## 6. 对话与表演

- **对话树（dialogue tree）**：适合关键场景、关系转折、信息交换；成本高，写作量大，容易变成「选完就忘」。
- **系统化短句（barks）**：战斗、探索、重复情境中的短反馈；成本低，能维持角色存在感，但要控制重复率。
- **对话即玩法**：*Disco Elysium* 把技能检定、内心声音、失败对话都变成叙事内容；对话失败也能推进，而不是「读档重来」。
- **表演**：动捕、面部、镜头、配音共同决定「这句话是否可信」。*God of War*（2018）用一镜到底的镜头语言强化「父子同行」的连续感；这类选择应服务体验目标，而不是炫技。
- **同伴设计**：同伴既是叙事载体，也是玩法工具（战斗支援、解谜、情绪反馈）。同伴的「无用时刻」往往最像人。
- **对话节奏**：walk-and-talk 适合关系建立；可打断/可沉默适合权力关系；长对话要给玩家「退出」的余地。

## 7. 叙事节奏与玩家控制权

- **过场长度**：过场越长，玩家越被动；把必须「看」的信息压缩到最短，把可以「做」的信息放进玩法。
- **控制权剥夺**：夺走控制权是有代价的，必须换取足够的信息或情绪；频繁剥夺会让玩家烦躁。
- **跳过与回顾**：允许跳过（尊重重玩/无障碍），提供回顾（尊重间隔游玩）。这两件事不破坏叙事，反而扩大受众。
- **叙事节拍与玩法节拍**：大战之后适合叙事沉淀；重大揭示之后适合立刻给玩家一个可执行目标；不要把两个高潮叠在同一分钟。
- **安静的设计**：留白、赶路、营地、雨天，都是让玩家消化情绪的空间。没有安静，高潮会贬值。

## 8. 案例拆解（可迁移的经验）

| 作品 | 叙事做法 | 可迁移的经验 |
| --- | --- | --- |
| *God of War*（2018） | 一镜到底、父子同行、把「过去」做成可探索的空间 | 镜头连续性可以服务关系叙事；把背景故事变成可选空间 |
| *The Last of Us Part II* | 双视角、暴力后果、大量可访问性选项 | 让玩家体验「另一方的理由」；无障碍是叙事可达性的一部分 |
| *Hades* | 死亡循环即叙事装置，每次失败推进关系 | 把「重试」写进世界观；失败也可以是内容 |
| *Outer Wilds* | 22 分钟时间循环，知识是唯一进度 | 用「理解」替代「数值」作为成长；玩家知道得越多，世界越打开 |
| *Disco Elysium* | 技能即内心声音，对话失败也推进 | 把角色内在做成系统；失败可以是新的叙事分支 |
| *Elden Ring* | 极简过场、环境与物品叙事、开放战场 | 留白可以制造探索欲；世界本身可以是最大的叙事文本 |
| *Death Stranding* | 负重、路线规划、异步连接 | 把「连接」这种抽象主题做成可操作的移动与建造 |
| *Spec Ops: The Line* | 让玩家执行暴力，再迫使玩家反思 | 失调可以成为主题，但需要明确的作者意图与铺垫 |
| *Undertale* | 「不杀」是完整路径，系统记得你的选择 | 机制层面的选择比对话选项更有重量 |
| *Gone Home* | 无战斗，纯环境叙事 | 空间与物件可以独立承担完整故事 |

## 9. 叙事设计流程与角色

**流程**：

1. **前提（premise）**：一句话故事。
2. **主题（theme）**：故事在论证什么。
3. **戏剧问题**：玩家/角色想知道答案的问题。
4. **人物**：want / need / 弧光 / 对手。
5. **节拍（beats）**：主线事件与转折。
6. **玩法映射**：每个节拍对应什么玩家动作、什么系统状态、什么空间。
7. **脚本与对话**：场景、对白、barks、可选文本。
8. **整合**：把叙事变量接入任务、关卡、对话、UI、存档。
9. **可读性测试**：第一次玩的玩家能否复述「发生了什么、为什么」。

**角色分工**（参考 Liz England 的《The Door Problem》）：

- **编剧（writer）**：故事、角色、对白；
- **叙事设计师（narrative designer）**：把故事翻译成系统、任务、状态与空间；
- **关卡设计师**：用空间与节奏承载叙事；
- **系统设计师**：让机制与叙事变量对接。

「门能不能开」这类问题之所以经典，是因为它同时涉及叙事、关卡、程序、UI、音频、QA——叙事设计的核心工作就是跨这些边界做决定。

## 10. 常见误用

- **把叙事等同于过场**：以为故事只在播片里发生。
- **叙事与机制各写各的**：剧本鼓励和平，机制奖励屠杀，且没有反思设计。
- **选择没有后果**：选项很多，世界毫无反应。
- **后果不可见**：做了重大选择，玩家却不知道发生了什么。
- **信息靠文本堆**：把设定集塞进可收集日志，玩家没有动机读。
- **环境叙事过度隐晦**：作者知道答案，玩家永远猜不到。
- **同伴只会说提示**：同伴变成会说话的 UI，而不是角色。

## 11. 讨论检查清单

- [ ] 故事的主线由哪些「玩家动作」推动？如果全是过场，问题在哪？
- [ ] 玩家在两次高光之间，有什么可自主产生的故事？
- [ ] 空间/物件承担了哪些叙事信息？第一层、第二层、第三层分别是什么？
- [ ] 故事承诺的价值，与机制鼓励的行为一致吗？如果不一致，是有意为之吗？
- [ ] 关键选择是否满足「知情、有分量、有反馈、有持续」？
- [ ] 分支结构是什么？成本可控吗？玩家回看时会觉得被尊重吗？
- [ ] 有没有一个「主题动词」被做成了可重复的机制？
- [ ] 过场是否只承担了玩法无法表达的信息？能否缩短或交互化？
- [ ] 玩家的失败/重试在故事里有没有解释？
- [ ] 第一次玩的玩家能否复述「发生了什么、为什么」？
